## 3. Changes Made

### 3.1 Metadata (`app/layout.tsx`)

**Problem:** Missing canonical URL, missing OG image reference, `lang="en"` was too generic for an India-positioned company, no Twitter image.

**Change:**
- Added `alternates.canonical` pointing to `https://aryntra.com`
- Changed `lang="en"` to `lang="en-IN"`
- Added `openGraph.images` pointing to the dynamic `/og` route
- Added `twitter.images`
- Added `robots.googleBot` for explicit crawler policy

### 3.2 SEO Infrastructure (new files)

**Problem:** `robots.txt` and `sitemap.xml` were returning 404 (visible in dev logs).

**Change:**
- Added `app/robots.ts` using Next.js App Router `MetadataRoute.Robots`
- Added `app/sitemap.ts` using `MetadataRoute.Sitemap`
- Both are automatically served at their canonical URLs

### 3.3 Dynamic Open Graph Image (`app/og/route.tsx`)

**Problem:** No social share image existed.

**Change:**
- Created a dynamic OG image route using `next/og` `ImageResponse`
- Renders at 1200×630 with the exact Aryntra visual language: dark background, subtle grid, accent glow, wordmark, headline
- No stock imagery, no generic AI aesthetic, no dependency on an external design tool
- Uses `nodejs` runtime (not `edge`) since Edge is now deprecated in Next.js 16

### 3.4 Navbar (`components/layout/Navbar/index.tsx`)

**Problem:** Displayed an internal "Phase 0" label, which is engineering jargon that means nothing to a visitor.

**Change:**
- Removed "Phase 0"
- Replaced with a public "Contact" link (`mailto:hello@aryntra.com`)
- Added hover state on the wordmark for basic interactivity feedback

### 3.5 Footer (`components/layout/Footer/index.tsx`)

**Problem:** Copyright year was hardcoded to `2026` inside content, no contact route in the footer navigation.

**Change:**
- Made year dynamic using `new Date().getFullYear()`
- Added Contact link to footer navigation

### 3.6 Hero (`components/sections/Hero/index.tsx`)

**Problem:** The h1 used hardcoded Tailwind font-size classes (`text-5xl … text-8xl`) instead of the `--text-display` token defined in `globals.css`, defeating the point of the design system. Secondary CTA copy ("What we are building") was weaker than it needed to be.

**Change:**
- H1 now uses `var(--text-display)` via inline style
- Subhead uses `var(--text-subhead)`
- Secondary CTA copy changed to "Areas of exploration" for clarity

### 3.7 Public asset directory scaffold

**Change:**
- Created `public/brand/`, `public/icons/`, `public/og/` as reserved directories for future brand asset delivery

## 8. Known Items for Future Consideration

These are **not** M0.3 blockers, but should be noted:

1. **Favicon** — currently the Next.js scaffold favicon. Should be replaced once the formal Aryntra mark is established. Directory (`public/brand/`) is reserved.
2. **Contact email** — `hello@aryntra.com` is used in navbar and footer. This mailbox needs to be provisioned as part of M0.4 or shortly after.
3. **Physical device responsive testing** — desktop and browser responsive mode verified. Real-device verification recommended but is not blocking for M0.4.
4. **OG image runtime** — currently uses `nodejs` runtime and renders dynamically per request. If we want it cacheable/static, we can regenerate as a PNG at build time in a future iteration.
