# S1.11 Decision Record — Aryntra Logo Integration

## 1. Objective
Surgically integrate the newly established Aryntra logo into the existing website, replacing text-only brand representations where appropriate, while preserving layout, typography, navigation, responsiveness, and design language.

## 2. Existing Brand Representation
- Previous state: Pure uppercase text string `Aryntra` in Navbar and `positioning.name` in Footer.
- Tagline preserved: `India's Intelligent Decision Layer`.

## 3. Master Asset Preservation
- Master Source: `docs/brand/source/aryntra-logo-master.jpg` (640x640 raster, completely untouched).

## 4. Production Derivatives Created
- `apps/web/public/brand/aryntra-symbol.png` (340x340 transparent PNG, antialiased for dark backgrounds).
- `apps/web/app/icon.png` (128x128 PNG for App Router automatic browser favicon detection).

## 5. Navbar Changes
- Integrated `[ Aryntra symbol ] ARYNTRA` lockup via `next/image`.
- Accessible name preserved with `aria-label="Aryntra — return to homepage"`, image marked decorative `alt=""`.
- Navbar height (h-16), layout, and mobile behavior preserved.

## 6. Footer Changes
- Brand mark integrated alongside `{positioning.name}`.
- Tagline, email contact, social links (Instagram, LinkedIn), index links, and copyright notice preserved.

## 7. Favicon / Icon Changes
- Added icon metadata to `apps/web/app/layout.tsx` pointing to `/brand/aryntra-symbol.png`.
- Established `apps/web/app/icon.png`.

## 8. Files Modified
- `apps/web/public/brand/aryntra-symbol.png` (new)
- `apps/web/app/icon.png` (new)
- `apps/web/components/layout/Navbar/index.tsx`
- `apps/web/components/layout/Footer/index.tsx`
- `apps/web/app/layout.tsx`
- `docs/decisions/S1.11-logo-integration.md` (new)

## 9. Deliberately Deferred
- OG route (`apps/web/app/og/route.tsx`) was left unmodified to protect existing dynamic OG image generation.
- Full tagline in logo artwork was omitted from UI repetition to maintain clean positioning.

## 10. Verification
- TypeScript: `tsc --noEmit` passed.
- Lint: ESLint passed.
- Production build: `next build` passed.
