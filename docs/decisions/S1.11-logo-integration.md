## 2. Master Asset Preservation & Derivative Engineering

### 2.1 Master Source Integrity
* **File Location:** `docs/brand/source/aryntra-logo-master.jpg`
* **Resolution:** 640 × 640 px (24-bit RGB JPEG)
* **Status:** **100% Preserved / Intact.** The source asset was neither modified, cropped destructively, compressed in-place, nor overwritten.

### 2.2 Derivative Production
The master image contains a composite composition (symbol, wordmark, tagline, dark background). Rather than deploying the raw rectangular JPEG into production contexts (which would introduce background color bleeding and scaling artifacts), automated mathematical extraction was used to derive transparent assets:

1. **`apps/web/public/brand/aryntra-symbol.png`**
   * **Bounding Box Analyzed:** $X \in [157, 481]$, $Y \in [113, 413]$ (340 × 340 px grid).
   * **Alpha De-blacking:** Applied smooth alpha-channel mapping based on pixel luminance ($L = 0.299R + 0.587G + 0.114B$) to remove the dark background cleanly while preserving anti-aliased edge smoothing and chromatic vibrancy.
   * **Purpose:** High-DPI transparent web symbol for UI lockups.

2. **`apps/web/app/icon.png`**
   * **Resolution:** 128 × 128 px PNG.
   * **Purpose:** Native Next.js App Router browser tab favicon asset.
